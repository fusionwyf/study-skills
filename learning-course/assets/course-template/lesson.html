本课要解决的问题

学完后你能……

写出一个可观察、可检查的动作结果，并说明它的适用条件。

先看一个具体情境

从一个熟悉例子开始。让学习者先预测，再给出解释。

核心解释

先用自然语言说明机制，再给出正式定义、规则或判断框架。

\(a^2 + b^2 = c^2\)

公式说明：写明符号含义、成立条件和使用边界。

代码或操作示例（适用时）

python
def check_result(value):
    return value >= 0

print(check_result(3))

说明输入、输出、运行环境和一个常见失败方式。

分步推导或操作

  1. 第一步：明确问题中的已知条件。
  2. 第二步：选择与条件匹配的规则。
  3. 第三步：执行规则并检查结果。

即时检查

哪一个选项最符合本课的判断规则？

先找出题目中的条件，再判断规则是否适用。

常见误区

误区：把结论当成无条件规则。

说明误区为什么产生、什么条件会使它失效，以及如何自检。

你来教 AI：纠正一个误解

下面是模拟学生的错误理解，请指出错误、说明适用条件，并给一个反例。

“只要背下结论，就可以在任何条件下套用；不需要解释为什么。”

对照要点：说明规则的前提；指出遗漏条件会怎样；用一个反例检验误解。具体主题应替换成可核验的概念与反例。

这些是自检要点，开放回答仍由老师结合原始记录评估。

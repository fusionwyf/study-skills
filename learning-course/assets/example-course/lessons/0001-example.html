变量：给数据一个可以重复使用的名字

本课要解决的问题

学完后你能……

区分变量名和它当前指向的值，并预测一次重新赋值后的输出。

先看一个记分牌

比赛开始时，名字 score 指向数值 10。得到 2 分后，名字不变，它指向的新值变成 12。

变量和赋值

在下面这行 Python 代码中，score 是变量名，10 是值，= 表示把右侧的值赋给左侧名字。

python
score = 10

= 在这里表示赋值

它让变量名指向一个值。它不是数学题里的“左右永远相等”。

运行顺序决定结果

先别看解释，预测下面程序会打印什么：

python
score = 10
score = score + 2
print(score)
  1. score = 10：名字 score 先指向 10。
  2. 计算右侧 score + 2：读取当前值 10，得到 12。
  3. 把 12 重新赋给 score，因此打印结果是 12。

即时检查

这段代码最后打印什么？
price = 8
price = price + 3
print(price)

按程序执行顺序逐行写出 price 当前指向的值。

两个容易混淆的地方

  • 变量名是 price，它的当前值才是 11。
  • 程序从上到下执行，后一次赋值会更新变量当前指向的值。

合卷检索

不看上文回答：在 age = 18 中，变量名和值分别是什么？如果下一行是 age = 19，此后打印 age 会得到什么？

小结与速查

  • 变量名让程序可以再次使用某个值。
  • = 把右侧计算结果赋给左侧变量名。
  • 重新赋值会更新变量当前指向的值。

几何与线性代数：剪切变换

A = [[1, 1], [0, 1]]，v = (x, y)，Av = (x + y, y)。蓝色实线 v 和红色虚线 Av 分别表示输入与输出；拖动 v 或通过数字框改变坐标。横纵每单位长度相同。

默认 v = (1, 2) → Av = (3, 2)；(1, 0) → (1, 0)，(0, 1) → (1, 1)。det(A) = 1，面积保持；长度和角度通常改变。数值显示保留 8 位有效数字，不等于符号精确计算。打印采用这些默认核对点。

算法回放：选择排序

输入 [5, 1, 4, 2, 3]，每轮从未排序部分选择最小值，与本轮起点交换。← 表示正在关注的位置；✓ 表示已固定的前缀。步骤由真实比较和交换计算生成，支持回退和键盘定位。

总比较次数 n(n − 1)/2 = 10，实际交换 4 次；交换次数取决于输入。看回放不等于会独立实现。

  1. a = input.copy()
  2. for i in range(n - 1): min_index = i
  3. for j in range(i + 1, n): compare a[j] < a[min_index]
  4. if smaller: min_index = j
  5. if min_index != i: swap(a[i], a[min_index])
  6. return a

解释与核验

对照要点（先作答）

Av = (1, 3)；第三轮结束后前 3 项已固定。每轮最小值被交换到当前位置；后续轮次只访问其右侧。此说明不自动评分。

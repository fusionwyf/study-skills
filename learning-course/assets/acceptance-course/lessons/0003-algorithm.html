一次完整的选择排序

输入 [3,1,2]。第一轮找到最小值 1，与首项交换，得到 [1,3,2]；第二轮交换 3 与 2，得到 [1,2,3]。每轮前缀有序，元素多重集保持不变。

python 
for i in range(len(a)-1):
    m = min(range(i,len(a)), key=lambda j:a[j])
    a[i], a[m] = a[m], a[i]

逐轮执行轨迹

  1. [3,1,2]
  2. [1,3,2]；首项已就位
  3. [1,2,3]；排序完成

选择排序的循环流程

寻找最小值 → 交换位置 → 检查前缀；有未排序项时重复。

# 十课组件验收

这些是能力样本，不代表真实学习者已经完成课程。数学/算法/概率使用原创推演；历史与设计使用明确标注的模拟材料；听力使用 Microsoft Zira Desktop 合成原创英文短句，只验收播放与作答流程，不代表自然语音训练效果。

## 课程契约

- 学习目标：验证全部课件组件的可复用资产、领域扩展与证据回流机制。
- 学习者：验证用合成学习者，不代表真实教学对象。
- 边界：本课程是验收夹具，不作为真实教学材料使用；领域内容为原创推演或明确标注的模拟材料。

## 成功标准

1. 独立推导平方函数的导数，并核对矩阵作用于二维向量。
2. 解释参数与分类图表的联动，并核对概率归一化。
3. 检查执行轨迹的不变量，并独立完成变式。
4. 区分材料、解释和局限，构造有依据的论证。
5. 基于图像位置与明确标准提出改进并解释理由。
6. 验证音频、文字稿、填空回答与学习记录流程。
7. 依据内容选择正确的版式、题型与可视化层级，并说明证据回流机制。

## 路线概览

第 0001–0006 课覆盖六类学科原型（数学/概率/算法/历史/设计/语言），每课验证一类资产组合与领域扩展；第 0007–0010 课覆盖组件组（版式与预测、六类题型、仿真与图表、证据回流），验证 Course Kit 的组件选择与证据闭环。路线固定，按课验收。

## 课件制作约定

- 结构与运行时由 `kit.py sync` 生成（`assets/kit/`、`assets/course/`），不手工维护副本；重可视化模块用 `kit.py add` 显式纳入（chart/spatial/plot/media）。
- 参数探索与仿真统一使用现代契约：`kit-param`（参数联动输出）、`kit-island`（时间旅行仿真，`kit.island.define` + `initialState/tick/actions/derive/view`）；可视化用 `data-visualization` + `data-viz-config`。
- 成熟第三方库优先，允许固定版本 CDN：算法代码用 highlight.js 11.12.0 CDN 引擎与官方 GitHub 明暗主题；数学排版用 KaTeX 0.16.11 CDN JS/CSS/auto-render；流程图用 Mermaid（`pre.mermaid`，由 content.diagram 模块加载）。图表与几何使用已登记版本的本地 Plotly/JSXGraph。
- 课程主题在 `assets/course/theme.css` 定制，自创主题放入 `assets/course/themes/<name>.css`（如 crt-terminal）并带 `@kit-theme` 头；由 sync 自动发现。
- 验收口径：结构校验、参数联动、步骤前后退、键盘热点、数值容差、填空匹配、原话记录、窄屏与打印后备；库的降级可读性与正常渲染分开验收。

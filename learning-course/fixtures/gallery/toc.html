3-State TOC & Responsive Rail Layout (L3 Shell Layer)

Demonstrates container-query responsive TOC: sidebar on desktop (≥1200px), floating popover on tablet (768–1199px), top bar + bottom drawer on mobile (<768px), with rAF scrollspy.

1. Introduction to Layout Architecture

Course Kit v2 adopts a 4-column modern container query layout: .kit-page, .kit-main, .kit-rail, and .kit-bleed.

2. Desktop Sidebar Mode

When the container width is at least 1200px, the table of contents is placed in the right rail as a persistent, sticky sidebar with collapsible sub-sections.

2.1 Collapsible Sub-headings

H3 subheadings automatically expand and collapse based on current reading position.

3. Tablet Popover Mode

Between 768px and 1199px, the TOC transforms into a non-intrusive floating popover button at the bottom-right of the viewport, preserving reading space.

4. Mobile Drawer Mode

Under 768px, a top summary bar indicates the current section, while clicking opens an accessible bottom drawer with focus trapping and gesture dismissal.

5. High-Precision rAF Scrollspy

Scroll position is sampled via requestAnimationFrame without triggering document-level jitter. The TOC container scrolls internally without disturbing the viewport.

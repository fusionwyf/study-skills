# 教学模式选择

## 使用方法

先确定本课的可验证学习成果，再选择一个主模式。可以组合两个模式，但不要把所有结构机械叠加到一课中。

## 概念理解

适用于科学概念、理论框架、术语体系和抽象机制。

推荐序列：

1. 让学习者先预测一个具体情境。
2. 展示现象、例子或反例。
3. 给出概念模型和关键关系。
4. 比较容易混淆的概念。
5. 用新情境检查能否解释和预测。

主要证据：解释、对比、预测、反例判断。

## 数学与定量推理

适用于公式、证明、计算和建模。

推荐序列：

1. 用数值、图形或问题建立直觉。
2. 给出严格定义及适用条件。
3. 分步推导，每步标明依据。
4. 完成一个示例，再做一个结构相同的练习。
5. 加入变式、边界条件或错误诊断。

主要证据：独立推导、选择方法、检查条件、解释结果。

可视化选择：函数/统计/曲面用数值绘图；几何构造/二维线性变换用约束联动实验。读取 `visualizations.md`。先预测，再改变参数，最后用代数、反例或证明核验；图像和有限采样不能充当证明。

## 编程与操作技能

适用于代码、软件工具、实验流程和设备操作。

推荐序列：

1. 展示目标产物和验收标准。
2. 给出最小可工作的示例。
3. 解释关键选择和常见失败方式。
4. 让学习者补全、修改或排错。
5. 完成一个独立小任务并验证结果。

代码示例必须写明运行环境、输入、输出和验证方法。不要用复制整段答案代替练习。

主要证据：可运行产物、测试结果、故障诊断和迁移实现。

算法可视化使用真实执行生成的状态序列，并联动数组、变量、代码位置和操作计数。读取 `visualizations.md`。让学习者预测下一步、指出不变量，再独立实现一个变式；看过回放不等于会实现。

## 语言学习

适用于词汇、语法、听说读写和翻译判断。

推荐序列：

1. 提供可理解输入和真实语境。
2. 引导注意目标形式及意义。
3. 做辨析和受控提取练习。
4. 进行简短输出。
5. 根据输出给出针对性反馈，再做延迟复现。

主要证据：主动提取、语境选择、理解与输出。不要只依据“认识这个词”。

## 写作、设计与创作

适用于文章、演示、视觉设计、音乐和其他开放性产出。

推荐序列：

1. 分析两个以上有差异的范例。
2. 建立简短、可观察的评价标准。
3. 完成一个局部创作任务。
4. 使用标准自评或互评。
5. 修订并说明修改理由。

主要证据：作品、评价判断、修订质量和决策解释。避免把审美偏好伪装成普遍规则。

## 历史、人文与社会科学

适用于材料分析、论证、观点比较和因果解释。

推荐序列：

1. 呈现材料、情境或冲突问题。
2. 区分事实、解释和价值判断。
3. 比较不同来源和立场。
4. 构造主张—证据—推理链。
5. 加入反例、替代解释或证据局限。

主要证据：来源判断、论证结构、反论证和不确定性表达。

## 判断与决策

适用于商业、医学常识、法律常识、安全、策略和复杂选择。

推荐序列：

1. 明确目标、约束和不可接受结果。
2. 建立判断维度或决策规则。
3. 比较多个案例。
4. 处理边界情况和冲突信号。
5. 让学习者做决定并解释权衡。

主要证据：条件识别、权衡说明、边界意识和错误成本判断。高风险领域必须清楚标注专业边界。

## 跨模式通用规则

- 用一个成果组织一课，而不是用一个术语组织一课。
- Worked example 之后安排 completion problem，再安排独立任务。
- 错误选项必须对应真实误区，并提供原因解释。
- 在课程后续使用旧知识解决新问题，实现交错与迁移。
- 学习者失败时先诊断失败类型：知识缺口、步骤负荷、表征困难、动机脱节或任务表述不清。

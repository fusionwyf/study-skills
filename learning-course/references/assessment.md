# 诊断与评估

仅在新建课程、设计练习、安排检查点或判断是否升级难度时读取本文件。

## 最小诊断

只有起点不确定且答案会改变课程路线时才诊断。题数和形式由 Agent 按主题决定，只获取足以选择起点的证据。

诊断的目的不是打分，而是发现关键前置缺口、误解或任务负荷。记录原始回答、提示使用和证据强度；不要因为一次猜对或主观自评判定掌握。

## 练习梯度

- **模仿**：学习者按照刚展示的结构完成近似任务。
- **补全**：保留目标结构，隐藏关键步骤，观察能否提取规则。
- **变式**：改变数字、表述、顺序或表面情境，保持核心关系。
- **迁移**：换到新场景，要求选择方法、解释边界或解决真实问题。

至少在一课或模块检查点中包含比示例更难的变式；只做同构题不能证明迁移。

## 证据与升级

证据优先级：

1. 独立完成新场景任务。
2. 独立解释、比较、纠错或说明限制。
3. 熟悉任务中的独立完成。
4. 有提示完成。
5. 选择题、识别题和主观信心。

任何学习反馈都可以保存为 evidence。只有低层或自评证据时，保持当前难度并安排针对性诊断；不同表述的回忆、应用或迁移表现达标后再升级 mastery。

## 综合评估

模块检查点不使用独立状态对象。将综合任务作为 `assessment` evidence 附加到相关 objective；证据冲突或缺失时使用 `uncertain`。

## 错误诊断

把错误归类后再调整教学：

- **知识缺口**：缺少术语、规则或前置事实。
- **表征困难**：看不出问题与模型的对应关系。
- **步骤负荷**：理解局部，但工作记忆无法保持完整流程。
- **条件误判**：知道规则，却不知道何时适用。
- **迁移失败**：在示例中会做，换情境就不会。
- **反馈不足**：没有足够行为证据，不能确认原因。

不同错误使用不同干预：补前置知识、换表征、拆步骤、增加辨析、加入变式，或先做更小的诊断任务。

# 来源与出处（Source Provenance）

登记来源、摘录原文、生成合成内容、或判断来源冲突时读这里。字段契约见 [`../schemas/source.schema.yaml`](../schemas/source.schema.yaml)；各 skill 的具体载体（考试包 SOURCES.md、课程来源区块）由各自的状态文档定义。

## 可靠性层级

多个来源冲突时按此顺序取舍：

```text
official（官方规范、真题、官方样题）
> course（教师划定的范围、作业、强调点）
> user（用户笔记）
> synthetic（Agent 生成）
```

判断不了就记 `unknown`，不得猜成 official。弱来源不得被静默当作官方范围；不确定的来源主张要显式标记。

## 注册

每个进入学习系统的来源都注册一条记录：`source_id`、标题、类型、可靠性、登记日期、覆盖范围。原始文件保留在包内；只提取当前任务需要的章节，摘录逐字保留并标注位置。

## 合成内容

Agent 生成的题目、示例和变式永远携带合成标记，并注明派生自哪条来源（如 `synthetic-from-Q0001`）。合成内容不伪装成官方材料；向用户交付时说明这是生成的变体。

## 未验证事实

无法追溯到具体来源的外部事实显式标记为未验证（unverified），并让用户可见。稳定常识、原创示例和纯推导不需要来源，但要能被识别为"无需来源"，而不是漏标。

## 冲突处理

高可靠性来源胜出。冲突本身显式记录（谁与谁冲突、依据什么取舍），不静默取舍；被弃用的说法保留在记录中可追溯。

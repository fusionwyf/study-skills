# 迁移与证据等级（Transfer Rubric）

设计练习、判断证据强度、或决定是否升级掌握度时读这里。课程侧把它落到 objective 的 mastery；考试侧把它落到 readiness 证据的取舍。

## 证据阶梯

从弱到强：

```text
recognition 认出
→ explanation 解释
→ application 应用
→ variation 变式
→ transfer 迁移
```

每一级需要的行为：

- **recognition**：在选项中认出正确答案或"见过这个"。选择题、识别题、主观信心只能证明这一级。
- **explanation**：用自己的话说清为什么、边界条件和反例。
- **application**：独立完成熟悉形态的任务。
- **variation**：换参数、换表象、换提问方向后仍能完成。
- **transfer**：带进全新场景，自己选择方法并解释取舍。

## 练习梯度

任务按此递进：模仿（按刚展示的结构做近似任务）→ 补全（隐藏关键步骤，观察能否提取规则）→ 变式（改变表面特征，保持核心关系）→ 迁移（换到新场景选择方法）。检查点至少包含比示例更难的变式；只做同构题不能证明迁移。

## 升级与降级

- 独立完成新场景任务是最强升级证据；独立解释、比较、纠错次之；熟悉任务的独立完成再次之；有提示完成居中。
- 选择题、识别题和主观自评是弱证据，不能独立升级任何掌握度。
- 只有弱证据时，保持当前难度并安排针对性诊断。
- 不同表述的回忆、应用或迁移表现达标后再升级。
- 证据冲突或缺失时标记 uncertain，不猜。
